# Security Policy

## Reporting

Please avoid posting credentials, private infrastructure details, unpublished artifacts, or sensitive reproduction data in public issues.

For security-sensitive or privacy-sensitive findings, use GitHub's private vulnerability reporting workflow when available. If it is unavailable, open a minimal issue requesting a private contact channel without including the sensitive material.

## Scope

This repository contains research code and reproducibility artifacts. Security reports should focus on credential exposure, unintended disclosure, dependency risk, or behavior that could materially invalidate the documented experimental protocol.
