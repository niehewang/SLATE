# SLATE P3C v1

One-shot held-out confirmatory for LLM-DNA/RepTrace Full-SLATE.

Run:
```bash
bash SELFTEST.sh
bash RUN_THIS.sh
```

Expected return:
`/data/jx-vmlab/SLATE_SERVER_RETURN_PUBLISHED_BASELINES_STAGEP3C_LLMDNA_FULLSLATE_HELDOUT_CONFIRMATORY_V1.tar.gz`

The launcher always tries to create a return package, including on failure. If the frozen-detector rebuild audit fails, held-out is not touched.
